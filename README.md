☕ Coffee Shop Sales Analysis Dashboard

A modern, interactive Power BI dashboard that provides insights into coffee shop sales performance across different store locations, product categories, and time periods. This project demonstrates how business intelligence can be used to transform transactional data into actionable insights for decision-making.

Project Overview

The Coffee Shop Sales Analysis Dashboard was built in Microsoft Power BI to help stakeholders monitor sales performance, identify best-selling products, analyze customer purchasing trends, and compare store performance.

The dashboard enables users to:

Track overall sales revenue
Analyze monthly sales trends
Compare store performance
Identify top-selling product categories
View product-level transaction breakdowns
Monitor unit prices and transaction quantities
Generate business insights for management
